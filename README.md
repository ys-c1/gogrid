# gogrid

网格地图的小型工具库：解析、A* 寻路、逐格视线（Bresenham）以及扇形视线投射。

## 视线投射

`Visible(a, b)` 只能回答“这两格之间通不通”，看不到一整片扇区里哪里被墙挡住。
`Project` 按张角与半径扫出一片可见扇区，并由最终可见格反推每个被遮挡格
是被哪面墙挡住的：

```go
g, _ := grid.Parse([]string{
    "..........",
    "..........",
    "....###...",
    "..........",
    "..........",
})

cfg := grid.CastConfig{
    Origin:    grid.Point{X: 0, Y: 2},
    CenterDeg: 0,   // 中线朝 +x
    AngleDeg:  90,  // (0, 360]，360 即全开
    Radius:    6,   // [1, MaxRadius()]
}
p, err := g.Project(cfg)
vis := p.Visible()     // 最终可见格（行优先）
occ := p.Occluded()    // 被遮挡格 + 其挡墙
st := p.Stats()        // 射线数、一致率、回退次数、距离场规模
```

| 方法 | 含义 |
| --- | --- |
| `Project(cfg)` | 扫掠 + 逐格对照，返回可见格、遮挡源、距离场与统计 |
| `PerCellVisible(cfg)` | 只用逐格 Bresenham 射线算扇形可见集（对照基准） |
| `RayBudget(angle, radius)` | 由张角与半径反解所需射线数 |
| `Visible(a, b)` | 原有逐格视线接口，语义与实现均未改动 |
| `MaxRadius()` | 合法半径上界 `ceil(hypot(W,H))` |

### 算法与三段流程

1. **扫掠**：按 `RayBudget` 反解出的条数等角步长转动，每条射线从观察点格心
   出发做 DDA 遍历，进入墙格立即停止。射线恰好穿过网格角点时，若对角格是墙
   则以它为挡墙；若对角格可走但两侧正交格有一面是墙，视为卡在零宽墙缝上，
   就地停下——不允许斜穿墙缝。
2. **逐格基准**：扇形几何掩码（半径 + 张角）内逐格用 Bresenham 判定，
   与 `Visible` 同一口径，结果作为权威可见集。
3. **对照与反推**：扫掠结果与逐格基准逐格比较，不一致的格由逐格基准裁定并
   计入回退次数；再由最终可见集反推被遮挡格及其挡墙。

### 两条不变量（分开核验）

- `CheckConsistency()`：重新用逐格 Bresenham 算一遍，最终可见集必须与之**逐格全等**。
- `CheckNoWallCrossing()`：扫掠射线不得跨墙。除了“墙格必须是射线末端”的结构检查，
  还做几何复核——枚举半径内墙格方块，射线在撞墙停止点之前不得穿入任何一个
  墙格方块的开内部（只擦过角点或边线不算穿过）。这两条各自独立返回错误。

### 射线数反解

最外圈 `R+0.5` 处相邻射线的弧长不得超过 1 格，故角步长上限为 `1/(R+0.5)` 弧度，
所需条数为

```
ceil(张角弧度 × (R + 0.5))
```

`Project` 恰好投射这么多条射线，`CheckBudget()` 逐次核验实际条数不超过反解值。

### 参数错误

错误均以参数名开头，可用 `errors.Is` 判定：

| 情形 | 错误 | 信息前缀 |
| --- | --- | --- |
| 张角为 0 / 负数 / NaN / Inf / >360，或中线角度非有限 | `ErrAngle` | `angle:` |
| 半径 <1 或 >`MaxRadius()` | `ErrRadius` | `radius:` |
| 网格为空 / 零尺寸 / 行宽不一致 | `ErrGrid` | `grid:` |
| 观察点越界或为墙 | `ErrOrigin` | `origin:` |

## 测试

```sh
go test ./...
```

覆盖：三类参数错误（含边界合法值）、五个样例场景（单墙、走廊、柱状、角落、全遮挡）
在多观察点 × 多张角 × 多中线 × 全半径下的逐格全等、射线不跨墙、射线数上限、
对角线墙缝不得斜穿、重复投射的确定性、被遮挡格挡墙的正确性。

## 统计命令

```sh
go run ./cmd/losstat                          # 样例集 + 迷宫 + 两档网格
go run ./cmd/losstat -scenario 单墙 -center 0 -angle 90
go run ./cmd/losstat -map '.....,..#..,.....' -x 0 -y 0 -angle 90 -center 0 -radius 4
```

输出包含：每张样例地图的射线数、反解上限、可见/原始格数、回退次数、一致率与
距离场规模；迷宫单独给出 45/90/180/360 四档张角的明细与可见图（`o` 标出被遮挡
的可走格）；两档网格（21×21 与 41×41）各列一行，对比回退次数与距离场规模。
